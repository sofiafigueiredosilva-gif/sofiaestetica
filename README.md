# 💖 Sofia Estética - Quiz de Procedimentos Estéticos

Um site interativo que ajuda você a descobrir qual procedimento estético é ideal para você através de um quiz personalizado!

## 🎯 Objetivo

Este projeto oferece um quiz inteligente que:
- Faz perguntas sobre suas preocupações estéticas
- Considera sua idade, orçamento e preferências
- Avalia seu nível de tolerância à dor e tempo de recuperação
- Recomenda o procedimento mais adequado para você
- Fornece informações detalhadas sobre cada procedimento

## ✨ Características

- ✅ **Quiz Interativo** - 8 perguntas bem pensadas
- ✅ **Inteligente** - Sistema de pontuação baseado em múltiplos fatores
- ✅ **12+ Procedimentos** - Botox, preenchimento, laser, rinoplastia, e mais
- ✅ **Design Responsivo** - Funciona perfeitamente em celular, tablet e desktop
- ✅ **Interface Moderna** - UI bonita e intuitiva com cores atrativas
- ✅ **Informações Detalhadas** - Tempo, recuperação, durabilidade, preço de cada procedimento
- ✅ **Recomendações Alternativas** - Sugestões adicionais baseadas no resultado
- ✅ **Compartilhar Resultado** - Opção para compartilhar em redes sociais

## 🚀 Como Usar

1. Acesse o site
2. Clique em "Iniciar Quiz"
3. Responda as 8 perguntas sobre você e suas preferências
4. Receba uma recomendação personalizada
5. Explore os detalhes do procedimento recomendado
6. Considere as alternativas sugeridas
7. Compartilhe seu resultado!

## ⚠️ Aviso Importante

Este site é apenas para fins educacionais e de orientação geral. **Não substitui a consulta com um profissional especializado**. Sempre consulte um dermatologista ou cirurgião plástico qualificado antes de realizar qualquer procedimento estético.
